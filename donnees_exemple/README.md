# Données d'exemple

Jeux de données fictifs utilisés par les tests et la démonstration. Chaque lot y dépose les siens.

Le cas commun est le **client B** : CII de 30 % à 20 %, 400 000 € de dépenses éligibles, 40 000 € en jeu, échéance dans six semaines.

Aucune donnée réelle de client ne doit être déposée ici.
